## 本机管理员与数据

未配置 `DATABASE_URL` 时使用下述本机 SQLite；配置后，网站和管理员命令使用对应的 Supabase 数据库。准备导入本机数据时应先迁移，再按需创建云端管理员，避免将目标空库提前写入业务数据。

首次设置时，在项目目录的交互终端运行：

```powershell
npm.cmd run admin:create
```

按提示自行填写用户名及两次密码。用户名为 3–64 个英文字母、数字、点、下划线或连字符，首位为字母或数字，保存时转为小写；密码为 12–128 个字符且不能全为空白，输入不回显。没有默认账号或密码，不要把密码写进命令参数、源码或文档。随后通过用户图标进入 `/me`，点击资料卡的账号按钮，也可直接访问 `/me#account`；旧 `/admin` 自动转到这里。未设置时初始化说明收在账号弹窗的折叠站点设置中，不在公共社区放置命令或管理员链接。普通社区阅读不依赖创建管理员。

忘记密码时运行以下命令，按提示输入已有用户名与新密码。它只修改该管理员密码并撤销其所有会话，不删除精选和帖子。

```powershell
npm.cmd run admin:reset
```

登录会话有效期为 8 小时，使用 HttpOnly、SameSite=Strict cookie；HTTPS 地址另带 Secure 标记。退出只撤销当前会话；重设密码撤销该管理员全部会话。数据库保存带盐的密码派生值和会话令牌摘要，不保存明文密码。管理 API 校验服务器会话与请求来源，不能仅靠修改浏览器状态取得权限。页面提示成功后才表示站点保存完成。

数据库默认位于项目的 `.data/studentpath.sqlite`，通过 `STUDENTPATH_DATA_DIR` 可指定另一数据目录；网站进程与管理员命令必须使用同一目录，数据目录不能放入 `public`。它保存管理员、会话、站点帖子、精选及管理员明确保存的指南／须知正文、配图和留学生活页面文案，不包含浏览器里的头像昵称、旧个人图片、个人情况、草稿、评论、收藏、清单与日期。现有浏览器精选不会自动导入服务器。初次初始化的 12 条示例与 9 条编辑精选只写入一次，主动清空精选后不会在刷新或重启时补回。

备份前停止所有使用该目录的网站进程与管理员命令，再完整复制 `.data`（或指定数据目录）到私有备份位置，保留可能存在的 SQLite 附属文件。恢复时同样先停止服务，使用完整备份恢复该数据目录再启动；不要在运行中仅复制主数据库文件。备份包含管理员安全记录，应由维护者保管；`.data` 与 SQLite 文件已加入忽略清单，不提交到公共仓库。浏览器个人记录需另行保留，站点数据库备份不覆盖它们。

1.48 起管理员新增的社区照片存于数据目录的 `community-media`，通过受控 `/media/community/uploads/` 地址读取，须随整个数据目录一起备份。旧导入照片仍在 `public/media/community/`，也要保留。编辑移除图片只修改帖子引用，不删除原文件；个人笔记不会自动上传到此目录。

本机模式使用 Node.js 内置 `node:sqlite`，默认开发与本机启动命令只监听 `127.0.0.1`。1.57 已完成 Supabase 迁移及 [Vercel 正式部署](https://wangye-opal.vercel.app)，跨设备行为尚未完成功能验收。服务器可选的 `STUDENTPATH_ORIGIN` 用于固定允许的完整来源；非本机来源要求 HTTPS。
