## 可采用的免费地图

[2GIS 官方 Map Constructor 文档](https://docs.2gis.com/en/maps/others/map-constructor/overview)说明该工具生成可嵌入的互动栅格地图，无需 API key 或订阅；常规流程在 Platform Manager 登录后编辑标记、线和区域，再复制 iframe。

本次从该官方文档的公开演示 iframe 读取到组件地址 `https://platform.2gis.ru/api/map-constructor/widget?data=...`。其公开参数是 JSON 经 zlib 压缩后做无填充 base64url 编码；包含 `orderedGeometries`、`mapPosition`、`scrollWheelZoom`。此参数格式来自官方公开输出，属于实际输出格式观察，不声称它是另外发布的稳定 API 规范。

      "type": "Feature",
      "properties": {
