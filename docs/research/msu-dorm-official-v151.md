# 1.51 莫大宿舍：官方分类与地址核对

核对日期：2026-11-17。供新增住宿帮助文章使用；本文件只记录事实核对，不修改业务代码、数据库或用户记录。本轮未运行测试、类型检查、lint、构建或浏览器验收。

## 分类范围

莫大联合工会的学生委员会介绍明确列出七个独立学生宿舍园区：ДС、ФДС、ДСЛ、ДАС、ДСВ、ДСК、ДСЯ。这里的“七大宿舍”是七个宿舍群／园区名称，不是七种可自由选择的房型，也不是七幢楼。[官方介绍](https://opk.msu.ru/obedinenniy-studencheskiy-komitet-mgu/)

莫大国际事务页面另列有 Шаболовка 的 ДСШ，因此面向读者宜写“莫大七个主要宿舍区”，不要断言全校只有七幢宿舍或本篇覆盖全部住宿点。[国际学生抵达说明](https://international.msu.ru/arrival)

## 分配与入住：可写与不应扩大的内容

- 国际事务官方页面明确：学院间交换及本科、专家、硕士项目学生的住宿安排，由接收学院外事办公室提供。可写“出发前向本院系确认宿舍缩写、楼号、办理地点、到达时间和入住材料”，不把某学院某年的分配规则套到所有国际学生。[官方入口](https://international.msu.ru/arrival)
- 公开院系页面显示分配方式确实不同：国家管理学院通常使用 ДСЛ / ФДС；经济学院使用 ДАС / ФДС；法学院有 ДСЯ / ДСК / ДСВ / ФДС / ГЗ。此信息只用于阻止“人人任选七种宿舍”误写，不建议在总览列学院资格对照表。
- 本篇不导入价格、固定入住日期、门禁时间、实时空位、保证的房间人数或交通耗时。部分官方介绍没有更新日且保留旧交通线路、旧价格；楼宇地址和基本格局可作识别，个体实际房间安排仍以院系通知为准。
- 不把小红书中的体验、房间照片、费用或排名改成“我亲身住过七个宿舍”的口吻；可以写直接好读的对照与行前确认清单。本文没有读取小红书原文，原帖读取由主任务单独完成。
